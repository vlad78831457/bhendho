# web — фронт движка

Фронт по бланкам ядра и простая панель админа (ADR-64, ADR-66). Открыт только пользователю с ролью `admin`
(ADR-61): остальные видят «Нет доступа». Адрес — `/admin/`; фронт и ядро — один origin, `/api` проксируется.

Перенесён из `taleweaver-app-vr-ab/projects/05_schema_frontend` без экрана сказки (`src/tale/`, он уходит
в подразделение сказок) и без PWA-оболочки: админу офлайн не нужен.

| Часть | Файл |
|---|---|
| Каталог, формы, задачи, данные, кошелёк | `src/pages/Pages.tsx` |
| Рендерер бланка | `src/components/DynamicForm.tsx` |
| Проверки полей до отправки | `src/lib/schema.ts` |
| Сессия, обновление токена | `src/lib/api.ts`, `src/session.tsx` |
| Realtime | `src/lib/realtime.ts` |
| Доступ только админу | `src/App.tsx` |
| Панель админа: подразделения и бланки, память подразделения (последние 100, запись факта), настройки, выгрузка всей базы за период | `src/pages/Admin.tsx` (ADR-66) |

Проверка — `make test` в корне `bhendho` (сервис `web-test`: `tsc` и `vitest` в Docker).
Сквозные проверки в браузере вернутся вместе со сборкой системы (`orb-tale-eco`).
