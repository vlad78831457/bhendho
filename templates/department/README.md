# Заготовка подразделения

Из этой папки начинается новое подразделение на ядре OFFGRID (ADR-71): паспорт, бланки, прораб на Python SDK,
проверки в Docker и `CLAUDE.md` для агента, который будет писать подразделение.

## Новое подразделение за пять шагов

1. Скопировать папку в новый репозиторий.
2. Заменить `example` на код подразделения во всех файлах: `grep -rl example . | xargs sed -i 's/example/<код>/g'`.
3. Описать свои бланки в `module/forms/` и паспорт `module/module.yaml`; `make check`.
4. Написать обработчик в `worker/src/department/main.py` и тесты; `make test`.
5. Получить ключ в панели админа («Подразделения» → «Ключ подразделения») и запустить прораба с
   `CORE_URL` и `DEPARTMENT_KEY` — подразделение подключится само, без перезапуска ядра.

Что уже есть в примере:

- факт пользователя `example.note.v1`;
- задача `example.run.v1` с резервом 10 GC, счётом в двух единицах, ролью пользователя и результатом —
  новой заметкой;
- память подразделения `example.spend.v1` (`audience: adm`) — пример `ctx.remember`.

`BHENDHO_REF` в `worker/Dockerfile` и `check.Dockerfile` — версия ядра; закрепите на коммите или теге.
